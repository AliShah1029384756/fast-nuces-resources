# FAST-NUCES Resource Hub

A curated one-page resource portal for FAST-NUCES students, with semester links, course references, past papers, and project examples.

## Live Website

After GitHub Pages deployment:
- https://alishah1029384756.github.io/fast-nuces-resources/

## Features

- Hero section with quick context and stats
- Semester-wise browser (Semester 1 to 8)
- Curated repository hub
- Course directory with quick external references
- Past papers hub
- Reference project showcase
- Contribution guidance section
- Mobile responsive navigation and reveal animations

## Tech

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Open index.html in your browser
2. Or use any static server

## Deployment

This project is intended for GitHub Pages deployment from the main branch root.
